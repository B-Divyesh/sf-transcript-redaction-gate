Privacy policy

Transcript Redaction Gate processes browser-demo text in your tab. The CLI reads only files you choose.

What stays local

The browser demo does not save or upload transcript text or custom patterns. The CLI has no telemetry or network code while scanning.

Site storage

The demo may use session storage with keys beginning demo:trg:. It contains only the sample-mode marker and is cleared by Reset demo. It never reads or writes real transcript data.

Analytics and cookies

This site has no analytics, advertising trackers, third-party scripts, or cookies. Hosting may retain short-lived security access logs.

Control

Clear this site’s browser storage to remove its local demo marker. Redacted files and receipts remain only where you save them.

Contact

Use the project issue tracker linked from the product page. Do not include transcript contents or credentials in a public issue.
